# GEO 1.3.0

- 新增「石墨银」皮肤，首页、账单、记账、详情和导航统一设计；保留「经典」为默认，可在「设置 → 主题皮肤」随时切换并自动记住。
- 使用人支持多选、全选、清空和已选人数，不设固定人数上限；一笔金额不会按人数重复计算。
- 完整保存多人名单和历史姓名，支持修改/删除历史与附件、导出/导入；兼容旧单选账单，数据库采用保留数据的迁移。
- 兼容旧格式账本备份；新导出的 `.geodata` 为格式 2，需要 GEO 1.3.0 或更新版本读取。
- 预览版可以检测到同系列正式版更新。

安装前建议导出账本备份。请覆盖安装 `GEO.apk`，不要卸载旧版或清除数据。沿用旧版签名，versionCode 9 高于之前的正式版和预览版。
