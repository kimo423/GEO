# GEO 使用人多选升级

## 使用方式

记一笔 → 使用人（多选）。逐个点击可选中/取消；「全选使用人」选中当前全部可用项，「清空使用人」取消全部选择。显示已选人数和勾选图标，不设固定人数上限，经典与石墨银均支持。金额仍属于一笔账，不按人数重复计算或拆分。

已选的历史使用人可以单独取消。全选时选择当前可用的姓名，保留已选但已停用/无法关联的历史使用人；同 ID 已改名的使用人按当前名称重新选择。

## 数据兼容

- Room 4 → 5：只新增可空的 expense_people_json 列，不重建或清空旧表；旧单选记录以一个使用人读取，不改变原始姓名、金额、时间或附件。
- 多选采用结构化 ID + 姓名快照数组，姓名含分隔符也不会被拆错。旧单人列作为兼容字段保留第一项，完整名单以数组为准。
- 编辑时保留未更换的历史姓名，即使配置已改名或停用；名单变化计入修改记录，删除历史也保留名单与附件。
- 详情、首页、账单、历史记录显示完整名单；列表摘要可能按原有两行省略，详情可滚动查看全部内容。
- geodata 格式升级为 2，兼容读取旧格式 1。新备份不能导入旧版 GEO，避免旧版只保留第一个使用人。geocfg 配置格式不变。
- 导入按每人的历史姓名匹配本机 ID，未匹配的人保留姓名而不错误关联来源设备的 ID。同名历史人员不被合并。
- 选择数量不设业务上限，既有备份总大小与资源校验仍保留。

## 验证范围

- 256 人全选/重复全选/清空、单独取消、多选状态保存恢复。
- 128 人保存；改名、停用后仍保留旧快照；删除一名后的 127 人名单，修改审计与删除审计。
- 携带附件的多选账单完整导出、全量导入、同记录替换；不重复计算金额。
- 旧单选备份格式 1 的 SHA256/快照兼容；姓名含「、」仍是一个人。
- schema 1、2、3、4 升至 5，旧记录、UUID、余额和单人快照保留。
- 主机 Compose 界面实际点击全选/清空、选择两人、切换皮肤、保存并核对数据库名单。
