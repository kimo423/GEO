# GEO 1.2.0

## 本次更新

- 每笔支持 0～10 个附件，单文件最多 10 MiB、总计最多 30 MiB；复制到 GEO 私有存储，删除外部原文件不影响副本。
- 新增修改/删除历史：同一事件展示修改前后内容，移除的附件仍可从历史查看和保存。
- 新增 .geocfg 配置导入导出和 .geodata 完整账本/附件/审计备份；支持完全替换或仅替换匹配项，损坏文件先校验再处理。
- 数据库从 v3 非破坏迁移至 v4，保留旧记录；增加永久 UUID 和逻辑删除。
- 统一暖白/石墨/银灰界面，增加附件图标和数量；保留 24 小时制秒级记录时间。
- 1.2.0 起通过“设置 → 检查更新”手动检查 GitHub 正式版本，不再启动时自动请求。

升级后建议导出 .geodata 备份并妥善保存。完整替换导入会替换当前账本，请谨慎确认。
